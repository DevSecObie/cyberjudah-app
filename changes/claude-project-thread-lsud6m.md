- Security (audit H1, H2): the signed iPhone and Android builds load the signing certificate or upload key only after the dependency install, native project generation and CocoaPods steps, so third-party install scripts run before any key is on the runner. The iPhone beta build and the Android staging build now run in a `testflight` environment, so once that environment is limited to the release branch and holds the beta signing secrets, other branches can't read the Apple distribution certificate.
