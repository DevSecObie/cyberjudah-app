- Security (audit H1, H2): the signed iPhone and Android builds load the signing certificate or upload key only after the dependency install, native project generation and CocoaPods steps, so third-party install scripts run before any key is on the runner. The iPhone beta build and the Android staging build now run in a `testflight` environment, so once the owner limits it to the release branch and moves the beta signing secrets into it, other branches can't read the Apple distribution certificate.
