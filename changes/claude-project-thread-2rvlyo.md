- Delete account now deletes the account's synced data with the sign-in: notes, highlights, bookmarks, tags, links, Strong's and Nave lists, word marks, tabs, studies with their history, sync status and profile. CyberJudah's Firebase project runs no deletion function (the upstream one is deployed only to Bible Strong's), so the app removes them itself, through the same staging scope as every other write, before it deletes the login. Everything is listed first, so a failed read deletes nothing, and the login is kept if the data cannot be deleted, so the reader can try again.
- An account that signs in with Apple confirms with Apple once more, and the app revokes its Apple tokens before anything is deleted (App Store Review Guideline 5.1.1(v)). A different Apple ID cannot delete the account; closing the Apple sheet deletes nothing.
- The recent-sign-in check happens before any data goes, so a reader is never left with a login and no data.
