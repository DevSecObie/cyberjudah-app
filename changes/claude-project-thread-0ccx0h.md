# Class videos embedded wherever a class is referenced

- One player card for a class referenced anywhere, the Timeline article's card: the video's
  picture with the moment on it, the class's name and date under it. A tap plays it right there,
  starting at that moment, through CyberJudah's hosted video page. It never starts on its own with
  sound, only one plays at a time, and the playing time is kept like every other class player.
  Tapping the name opens the class and its notes.
- Where it now shows: a Bishop's commentary entry (its timestamp link plays the video below),
  the Timeline's articles, a person's "What the classes taught", a verse's Precepts sheet, a false
  doctrine's teachings and scriptures, the Glossary, a topic's Thread, a case's "Taught in" (when
  it is a class) and the Ask answer's class sources.
- Lists of classes with no moment (a person's "Classes that read of", a topic's "Classes and
  Episodes", the class library and search) stay as rows that open the class page and its player.
