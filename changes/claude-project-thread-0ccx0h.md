# The class video inside a commentary entry

- A Bishop's commentary entry now shows the class it was taken from, right under the entry: the
  video's picture with the moment on it (for example 1:35:20). Tapping it plays the class there,
  inside the entry, starting at that moment. It never starts on its own with sound.
- Tapping the entry's timestamp link plays the class below from that moment, instead of leaving
  the app for YouTube.
- The playing time is kept, as with every other class player, so the class page and the floating
  player pick up where it was left.
